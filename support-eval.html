Evaluating a support assistant.

A small, inspectable contract for routing and response content, available both as a local gate and an MCP tool.

Focus
Evaluation, routing, tool interfaces

Artifacts
Evaluator
Cases
MCP server

The problem

A support assistant needs to choose whether to respond or hand a request to a person. A plausible answer alone does not show that it followed the intended routing rule.

The approach

Three fictional requests define expected routes and required reply phrases. The evaluator checks candidate answers against both. All cases must pass for the command to succeed. The MCP server exposes the same grading function for a single known case.

Scope

This checks a narrow contract, not general answer quality or multilingual coverage. The dataset is deliberately small and fictional. More representative cases and human review would be needed for a real support system.
