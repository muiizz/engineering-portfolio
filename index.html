Selected case studies

Applied AI, clinical safety

Rules decide before the model does

Divia is a doctor-led diabetes coaching programme on WhatsApp. Every dangerous situation is caught by deterministic rules first. The language model is the second safety net, never the first.

In the live evaluation of 24 November 2026, 206 of 211 replies passed every automatic check, and all 22 urgent cases passed in all three runs.

Read the Divia case study

Two independent reads of a meter photo must agree before a value is accepted. A low value is escalated by rules at once and never reaches the model.

Applied AI, evaluation

When mutation tests missed a language gap

A strong mutation score hid a routing gap in a multilingual test set. Four revisions reduced missed urgent cases, while false alerts increased.

Read the safety case study

Missed urgent cases on the same 90 synthetic cases: 81 of 90 in the first revision, 3 of 90 in the fourth. False alert rate: 4.9% to 14.8%.

PostgreSQL, query performance

Find 96 rows in a million

A composite index reduced the median query time from 67.169 ms to 0.126 ms in five warm runs. Both queries returned the same ordered rows.

Inspect the query plans

Median execution time, five warm runs: 67.169 ms with the primary key only, 0.126 ms with the composite index. 96 ordered rows in both.

Seventeen gate proofs check that a flawed change fails for the expected reason. The published mutation run killed all 40 mutants.

Design notes

Paper #F4F6F7
Ink #14171A
Accent
Two base colours, one accent
Every grey is a mix of paper and ink. The accent is kept for errors and misses, so when it appears it means something.
One typeface
Archivo, a variable face. Width and weight do the work a second font would. Urdu text is set in Noto Nastaliq.
Readable first
Body text is ink on paper at a 16 to 1 contrast ratio, in lines under 80 characters.
Motion answers an action
Things move when you press, type or scroll. The reduced-motion setting turns it off.
Keyboard and touch
Every demo control is a real button or field, at least 44 pixels tall, with a visible focus ring.
Works without scripts
Each demo sits on top of the plain result it illustrates, so the numbers are there even if the script fails.
