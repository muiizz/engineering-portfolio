When mutation tests missed a language gap

A synthetic evaluation of deterministic routing in English, Roman Urdu, and Urdu script.

Why the order matters

The pipeline normalizes the message and checks rules before it can reach the model stub. Urgent matches and messages without consent cannot reach the stub. Property tests cover both paths.

What the evaluation found

The first revision killed 112 of 115 mutants while missing 81 of 90 urgent fixtures in the test split. Both Urdu-language groups had zero urgent recall. By the fourth revision, the engine missed 3 of 90. The false urgent rate rose from 4.9% to 14.8%. The final campaign killed 189 of 196 mutants.

The results are from 23 November 2026. The data contains 342 synthetic messages across development and test splits. The author wrote both the rules and the cases, so the test split was not independently authored.

What broke during iteration

Collapsing repeated letters helped the matcher handle spelling variants, but it also changed text that the output checker expected. A unit test caught the mismatch. The final pipeline uses separate normalization paths for routing and output checks.

Divia case study: evaluating the safety layer

I used two complementary checks to evaluate Divia’s deterministic routing layer. A multilingual audit exercised the system with 1,755 fictional messages in English, Roman Urdu, and Urdu script. A separate mutation campaign introduced 1,737 temporary changes to test whether the automated suite detected them.

The audit measured how the router handled different ways of expressing the same intent. Mutation testing measured whether the suite caught changes to code behavior. Together they informed two kinds of regression coverage: additional language examples and targeted tests for behavior the existing suite missed.

These were offline experiments on a historical revision using synthetic data. The results describe the coverage of those experiments. The open-source project above is a standalone teaching example with its own data and measurements.
